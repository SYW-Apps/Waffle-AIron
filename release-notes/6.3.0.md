# wairon 6.3.0

- Security: an API key narrowed to projects now stays within them on every hosted route; it can no longer act with its owner's wider permissions, and never holds the instance administrator's bypass.
- Spec lookup for assistants: `sdd_search_specs` finds any design element from an id, a name, a method, a type, an endpoint, a code file or a symbol, and `sdd_find_references` says who uses it, whether the code agrees with the design, and what a change would break.
- Type diagrams per group: `wairon diagram --types` draws the type groups and the references between them, `wairon diagram --group <id>` one group's types as a class diagram, and `--all` writes them all.
- `sdd_get_status` answers a summary by default; pass `detail: full` for the whole report.
- A type planned in a file another component already wrote stays a planned notice until its writers have code, instead of failing `validate --ci`.
- The CLI's credential store and settings take a write lock, so parallel `wairon login` or settings changes no longer lose one; `wairon mcp install` keeps a server the agent added meanwhile.
- Spec files are replaced atomically, so a command reading the tree during a write never sees an empty file.
- Upgrading: install 6.3.0, run `wairon generate`, reconnect your assistant's MCP server.
