# wairon 6.2.0

- Security: the release binaries now run Node.js 24.22.1 (the October 2026 Node.js security release, including the Brotli decoder fix); installed through npm, update your own Node.js to 24.22.1, 22.23.4 or 26.12.1 or later.
- Security: the canvas escapes every name it shows, so a design's text can no longer put markup into another user's view of a hosted server.
- Type groups form a tree: a group may name a parent group, the folders under `types/` follow it, and groups can be renamed and moved with their whole folder. Type ids stay bare and global.
- `wairon dev` always starts: a tree with errors opens with a findings panel listing them, and data an older version left behind is discarded instead of failing the start.
- A project of only types is a design: `wairon lock` approves its types and export table, and `status`, `validate` and `lock-check` no longer call it empty.
- Every reading names the release that produced it: `sdd_get_status` and `sdd_validate_tree` carry `validatorVersion`, and `wairon validate` prints it.
- Every hosted store locks its writes, so parallel admin changes (grants, units, roles, policy and the rest) no longer lose a change.
- Hosted project ids may contain `.` and `_`, revoked credentials are deleted, and `wairon surface diff` reports a reordered type's fields.
- Upgrading: install 6.2.0, run `wairon generate`, reconnect your assistant's MCP server. Do not run two wairon versions on one tree at the same time.
