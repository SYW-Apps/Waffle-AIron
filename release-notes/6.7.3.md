# wairon 6.7.3

- Closes the zod advisory GHSA-mrhx-c7xc-m3w5 (memory exhaustion validating oversized constrained collections): wairon validates with zod 4. What is accepted and refused, and the messages, are unchanged, except that an integer above 2^53 − 1 (such as a step number) is now refused.
- Installing `@wairon/cli` runs no install script and pulls in no telemetry package: the Swagger UI files the hosted server serves are copied into the package at build time (with their license) instead of being installed as a dependency.
- The terminal libraries (colours, prompts, command parser) are on their current majors, which drops the unmaintained packages the older ones pulled in; prompts, colours and output look and behave as before.
- The design export's JSON Schema is generated by zod 4 itself and describes the same document as before.
- wairon is marked experimental in the README, the npm descriptions and SECURITY.md: any release may change behaviour, and only the latest release is supported.
- Upgrading: install 6.7.3, restart or reconnect your AI tool.
