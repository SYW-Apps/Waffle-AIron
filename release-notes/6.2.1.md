# wairon 6.2.1

- A type's group can be removed: clearing it through the assistant (or `sdd_update_spec` / `sdd_add_type`) now really removes it, and a type leaving a declared group also leaves that group's folder. A type naming a group nothing declares can be corrected without editing files by hand.
- In a family where a member project has its own member project, a write refused at the top root now names the project that holds the spec, with its folder.
