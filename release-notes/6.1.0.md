# wairon 6.1.0

- `wairon upgrade` moves a project, and every project of its family, to the running major in one all-or-nothing step; it never locks.
- `wairon whatsnew` shows the release notes between the version a project was written by and the one you run.
- A hosted server upgrades its data directory when it starts.
- `wairon host doctor` is gone: the hosted server's upgrade replaces it.
- `wairon doctor` no longer carries the v5 repairs; they live in the upgrade's step.
