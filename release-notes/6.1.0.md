# wairon 6.1.0

- `wairon upgrade` moves a project, and every project of its family, to the running major in one all-or-nothing step; it never locks.
- `wairon whatsnew` shows the release notes between the version a project was written by and the one you run.
- A hosted server upgrades its data directory when it starts.
- `wairon host doctor` is gone: the hosted server's upgrade replaces it.
- `wairon doctor` no longer carries the v5 repairs; they live in the upgrade's step.
- **Breaking (hosted SSO):** an enabled SSO provider must name the addresses it may return to (`allowedRedirectUris`, or `WAIRON_OIDC_ALLOWED_REDIRECT_URIS`), usually `https://<your host>/web/sso/callback`. Until it does, it signs no one in; the admin Providers page, the save answer and the server start log name each such provider, and the login page shows it as not set up yet.
- **Breaking (hosted):** the hosted server reads only wairon 6 forms; older stored values are rewritten when it starts, and a retired value in an environment setting is refused, naming its replacement.
- A bare type name resolves in the subsystem that writes it first. A reference that matches several types, or lands on another type while a closer one carries that name, is reported as `AMBIGUOUS_TYPE_REF`; write the type's id or `subsystem::name` to say which is meant.
- `sdd_rename_type` respells only the references that resolve to the renamed type, refuses on an ambiguous or shadowed one (naming every site; `allowShadowed: true` renames anyway and lists them), and reaches either half of a duplicate type id as `subsystem::id`.
- A narrative's calls are judged by how much it states: with `detail` stated on a method or its implementation, every call its code makes into another component must be a step (`UNNARRATED_CALL`, which fails `--ci`); without it, a call to another collaborator is shown as a route the design leaves open (`OPEN_ROUTE_CALL`, a notice).
