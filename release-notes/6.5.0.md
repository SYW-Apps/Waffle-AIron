# wairon 6.5.0

- Python is checked like TypeScript for routes, data types and dependencies. Routes are read off FastAPI and Flask route decorators, data types off dataclass, Pydantic, TypedDict, NamedTuple and attrs classes, and a declared dependency between Python components must be visible in the code.
- A parameter's type is compared: `authorId: number` where the contract declares a string (or a Python `text: int`) is now `PARAM_TYPE_MISMATCH`, as a changed return type already was.
- A re-export is a dependency: republishing another component's code needs the same declared relation as importing it, and an import through a barrel is charged to where the name is declared.
- Stricter undeclared exports: a test or a composition root counts as using an export only when its call actually lands on it.
- The diagram functions behind `wairon diagram --subsystem`, `--sequence` and `--all` are part of the designed API; `loadSpecGraph` is no longer exported from the library.
- The hosted Tokens page lists each key's documented fields only, and a refused lock names the permission that refused it.
- Upgrading: install 6.5.0, run `wairon doctor --fix` and commit, restart or reconnect your AI tool, then run `wairon validate --ci`. It may report code that passed under 6.4.0.
