# wairon 6.6.0

- How a narrated call runs is compared with the code: awaiting a call marked `detach: true` is `DETACHED_CALL_AWAITED`, and a call inside a catching `try` step that no try/catch encloses is `CALL_NOT_CAUGHT`, in TypeScript and Python. A step whose manner could not be judged says so (`CALL_MANNER_UNJUDGED`).
- A data field's type is compared: a field annotated as another simple type than its spec declares is `TYPE_FIELD_TYPE_MISMATCH`.
- More Python is read: guard-style routers (`if`/`match` over the method and path, `do_GET`), a router named through a package `__init__.py` re-export, and calls between components written in one file. A TypeScript router named through a re-export (`export { }` or `export *`) is followed too.
- A plain `wairon validate` composes the externals inside a project's reach. A `../` sibling stays advisory, and live drift never fails `--ci`.
- Hosted: withdraw your own lock request, manage users with `wairon host user`, and stale or repeated lock requests are cancelled or reused instead of piling up.
- Upgrading: install 6.6.0, run `wairon doctor --fix` and commit, restart or reconnect your AI tool, then run `wairon validate --ci`. It may report code or pins that passed under 6.5.0.
