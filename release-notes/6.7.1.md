# wairon 6.7.1

- A parameter that takes one value where its contract declares a list or a set, or the reverse, is now `PARAM_TYPE_MISMATCH`, in TypeScript and in Python.
- A Repository that reaches its Store only through the Registry or Index it owns is no longer told `UNREALIZED_DEPENDENCY` for the Store.
- `sdd_set_public_interfaces` refuses `shared: true` on a component that is not an Adapter, and writes nothing.
- Hosted: a `/web/*` route missing its `projectId` says so (400), pack names starting with a dot are refused, and error bodies carry the error's message only.
- Upgrading: install 6.7.1, restart or reconnect your AI tool, then run `wairon validate --ci`.
