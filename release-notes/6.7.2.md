# wairon 6.7.2

- `PARAM_TYPE_MISMATCH` says a plain value mismatch (one value for a list, a number for a string) in two sentences, with the fix.
- Hosted: a pack install refuses a name Windows reserves for a device (`con`, `nul`, `com1`, …) and a second pack declaring a name a pack in the same folder already declares; reinstalling under the same name still replaces it.
- Hosted: a `/web/*` read that sent `project` instead of `projectId` is told so, and the CLI reference names the web app's project pages and the reads behind them.
- Upgrading: install 6.7.2, restart or reconnect your AI tool. Hosted: if a pack folder already holds two packs declaring one name, remove one of them.
