# wairon 6.1.2

- In a decorated TypeScript class (NestJS, Angular), a constructor parameter type imported from another component counts as a runtime dependency again (decorator metadata), so its `UNDECLARED_EXPORT` is reported.
- `wairon update` on Windows never leaves you without `wairon.exe`: a failed copy puts the running build back.
- Small fixes: no internal fields in early validation results, a clearer unstamped-project refusal, upgrade refusals naming files from the project root.
