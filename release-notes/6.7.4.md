# wairon 6.7.4

- `wairon dev` is the place to approve: the page follows the design live, an agent asks for a review or a lock with `sdd_request_review` and waits for the answer with `sdd_await_review`, and every lock shows what moved and the current warnings first.
- `wairon dev` has a Family tab for members, externals and the network, with each member command previewed before it runs, and it locks member projects from the parent.
- Validation is remembered across runs, restarts and branch switches: a repeat on an unchanged tree answers in seconds, and the dev page switches pages fast and draws the canvas before validation finishes.
- A Store is the default data component: simple state needs no Repository, Registry or Index around it. An Index that reads through an Adapter is now `INDEX_DOES_IO`, a warning.
- wairon ships as a plugin for Claude Code, Codex, Cursor, Antigravity and the Gemini CLI; a target marked `via: plugin` gets no second copy of the server or the skills.
- New MCP tools change a project's rules, debt register and settings (`sdd_update_rules`, `sdd_carry_findings`, `sdd_configure_project`), and packs can declare practices a project selects per scope.
- Install packs by name from the wairon pack registry: `wairon pack install @scope/pack`.
- Upgrading: install 6.7.4, run `wairon generate`, reconnect your AI tool, then `wairon validate --ci` (see the CHANGELOG for the two new warnings).
