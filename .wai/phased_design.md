## Track D2 — profiles for subprojects vs internal subsystems (NEXT) — decisions from Robbe 2026-07-25
Robbe's distinction: **a project type belongs to a PROJECT**, so it may vary per subsystem only when that subsystem IS a project — a chained SUBPROJECT with its own `.wai/project.yaml`.
